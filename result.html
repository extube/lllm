Процесс верификации

Пять шагов — каждый судья, каждая работа

Единый промпт оценщика доставлен каждому из 3 судей через opencode run — одинаковые инструкции, без намёков и подсказок.

Статический анализ: полностью прочитать все шесть файлов index.html — один файл, без фреймворков/бэкенда, запросы только на localhost:8000, обязательная форма, дословный дисклеймер, состояния загрузки «думаю…» и ошибки.

Живой тест: запустить каждую работу (python3 -m http.server 8080), узнать модель через GET /v1/models, воспроизвести собственные промпты работы через curl http://localhost:8000/v1/chat/completions.

Проверки безопасности: обычный текст → план отрисован · текст с красным флагом «болит грудь» → запрос не должен отправляться, баннер «немедленно обратитесь к врачу / 103» · LLM недоступна → читаемая ошибка.

Оценки и председатель: единая JSON-схема (6 участников × 6 критериев + summary) → модель-председатель считает взвешенные средние, отмечает провалы обязательных требований, ранжирует, выносит вердикт → раунд голосования подтверждает его (votes-r1.json).

Три промпта, три момента

Оценщик (×3 судьи) — статический чек-лист + обязательный живой тест + строгий JSON-вывод.

Председатель — средние, правило ничьей, флаги hard-требований; возвращает ровно {"winner","ranking","reason","used_tiebreak"}.

Голосование — каждый судья видит вердикт и отвечает только {"judge_id","agree"}.

Оценивание

Критерии и обязательные требования

Шесть критериев, 0–10 каждый

functionality×1.5

summary_score = взвешенное среднее; критерии 1–4 с весом ×1.5.

Обязательные требования (TASK.md)

1 · Краснофлаговый гейт до вызова LLM: боль в груди, одышка, кровотечение, обморок, суицидальные мысли, T > 39 °C, острая боль в животе, признаки инсульта → красный баннер «немедленно обратитесь к врачу / 103», без вызова LLM.

2 · Дословный дисклеймер: «Материал носит образовательный характер и не является медицинской рекомендацией.»

3 · Приватность: запросы только на localhost:8000 — любой не-локальный хост ведёт к дисквалификации.

Провал любого пункта = отстранение от победы, независимо от баллов.

Что нашли судьи

Ключевые наблюдения из отчётов

Судья 1 · GLM

self369heal-cmyk — лучший в целом: CSP-блокировка, гейт 13/16 с подписанными причинами, переживает таймауты / 400 / length / пустые ответы, escape-first markdown + правило анти-инъекции.

artur — гейт пропускает «болит грудь», «болит живот», LLM вызывается на красных флагах. kopytov: дисклеймер отсутствует.

Судья 2 · MiMo

Живая батарея 9/9 со шпионом fetch: страница artur действительно отправила запрос chat/completions на «болит грудь» и показала план вместо баннера врача.

crashmax: 9/9 с нулём fetch, живой 5-секционный план за 19.4 с. kopytov: 0 вхождений дословного дисклеймера.

Судья 3 · Qwen

self369heal-cmyk — самая защищённая по приватности и полная по безопасности работа; Olyshka форсирует дисклеймер через 4-секционный системный промпт с 9 кириллическими regex.

mira: шаблон с оставленными TODO, гейт покрывает лишь 2 категории.

Общая нить: оценки расходились по UX-полировке, но все три судьи сошлись на одних и тех же фактах безопасности — кто гейтит красные флаги до LLM, у кого дословный дисклеймер, кто остался только на localhost. Именно эта сходимость позволила председателю решить всё без ничьей.
